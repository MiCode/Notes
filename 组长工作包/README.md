# MiCode Notes 小组作业——组长工作包

本工作包依据课程的 4 份作业材料与 `MiCode/Notes` 的 `master` 分支整理，用于直接启动项目、完成组长第一阶段工作并给另外 3 名组员派工。

## 文件说明

- `组长工作成果与接续说明.md`：可直接改写进两份报告和汇报 PPT 的项目分析、架构分析、维护方案、测试计划与推进方法。
- `发给组员的任务通知.md`：一段可直接复制到小组群的任务通知。
- `便签置顶功能.patch`：组长负责的维护项“便签置顶/取消置顶”源码补丁。
- `用例图.puml`：系统用例图 PlantUML 源文件。
- `原始架构包图.puml`：原项目包级架构图 PlantUML 源文件。
- `置顶功能设计类图.puml`：组长维护项设计类图 PlantUML 源文件。

## 建议使用顺序

1. 先把 `发给组员的任务通知.md` 发到群里，并把“组员 A/B/C”替换为真实姓名。
2. 在小组仓库建立 `develop`，四个人分别从 `develop` 建个人分支。
3. 组长在自己的分支执行 `git apply 便签置顶功能.patch`。
4. 导入 Android 工程后完成编译适配，再按 `组长工作成果与接续说明.md` 中的用例实测并保存截图。
5. 将三张 `.puml` 图导出为 PNG，填入报告和 PPT。
